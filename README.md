# WinFast.com

The fast lane to free-to-enter sweepstakes, hackathons, prize challenges, scholarships and creative competitions — plus free giveaway tools, Win Alerts, brand promotion services, donations and WinFast skill contests.

Static site on **GitHub Pages (free plan, `main` branch, root)** using the built-in Jekyll build for one shared layout. AdSense-ready.

## Structure
- `_layouts/default.html` — shared head (AdSense), top interest bar, header, footer, consent, lead modal
- `*.html`, `tools/`, `guides/` — page bodies with front matter (generated by `scripts/build.py`)
- `assets/` — CSS, JS (forms, donations, tools runtime), images
- `data/opportunities.json` — curated listings (edit by hand; expired items auto-hide in the browser)
- `data/feed.json` — live hackathon feed (filled by `scripts/update-feed.mjs`)
- `data/contests.json` — contest rounds (set `status` to `open` and add a prize/deadline to launch)
- `docs/BUILD-PROMPT.md` — concept, revenue model, research and phase-wise build prompt
- `docs/github-workflows/` — GitHub Actions files to copy into `.github/workflows/`

## One-time setup
1. **Pages:** Settings → Pages → Deploy from a branch → `main` / `(root)`.
2. **Self-updating feed:** copy `docs/github-workflows/update-feed.yml` to `.github/workflows/update-feed.yml`, then run it once from the Actions tab.
3. **Forms:** submit any form once and click the activation link FormSubmit emails to the owner inbox.
4. **Custom domain:** add `winfast.com` in Pages settings, point DNS at GitHub Pages, enable HTTPS.

## Editing
Edit content in `scripts/pages_*.py`, run `python3 scripts/build.py`, commit.
