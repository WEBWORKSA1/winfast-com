FAQ

Is this giveaway picker really random?

Yes. It uses the browser's cryptographically secure Web Crypto API with rejection sampling, so every eligible entry has exactly the same probability.

Do you store my entries?

No. Everything runs in your browser; entries are never uploaded to WinFast.com.

How do I prove my draw was fair?

Download the draw certificate. It records the time, filters, eligible count, winners, alternates and a SHA-256 fingerprint of the final list so anyone with the same list can verify it was not changed.

Can I pick winners from Instagram or YouTube comments?

Yes — export or copy the comments, paste them one per line, and enable 'Treat the first word as the entrant' to dedupe by @handle.
